📖 Build Your Skill in AgentSpaces

Build your solution with the SC CORE Agent, raise a CR, then submit the CR link here. ~15–30 min (excluding permission propagation).

🎬 Watch the full walkthrough (9 min)

▶ Watch on Broadcast

✅ What you'll need

  • POSIX groups — toolbox-users-misc & source-code-misc (up to 4h to propagate)
  • Work Authorization — citizenship/nationality set in AtoZ → Work Authorization (Deemed Exports), ~15 min
  • Tampermonkey browser extension installed
  • ~15–30 min (excluding permission propagation)

🚀 5 steps

  1. Get AgentSpaces permissions — ask your manager to add you to both POSIX groups, and set your Work Authorization in AtoZ.
  2. Open the agent — install Tampermonkey from the EUSC AI Shortcuts page, then launch the SC CORE Agent. Manual option: in AgentSpaces type aim agents install SC_Manager_Core_Kit, open a new session with "+" and pick SC-MANAGER-CORE.
  3. Test the skills — ask "Which skills do you have?", run one, and try an operational question about your site.
  4. Give feedback — tell the agent if a skill was useful; it logs automatically to the Slack Feedback Tracker.
  5. Create your skill — chat & iterate until it works → say "Let's skillify this" → say "Let's raise a CR" pointing to SC_Manager_Core_Kit → paste the CR link in the Submit form here.

🎯 The skill lifecycle

Chat & iterate → Skillify → Raise a CR → Submit your CR link here → Merge & deploy → available to all managers
